PDF Atölye – yerel çalıştırma (12 araç)
1. cd pdf-atolye
2. python3 -m http.server 8000
3. Tarayıcıda http://localhost:8000 adresini açın.
Tüm kütüphaneler klasörde, internet gerekmez. (index.html'e çift tıklayarak açarsanız
PDF → JPG, PDF → Metin ve Sıkıştır araçları pdf.js'i internetten yüklemeye çalışır;
bu yüzden sunucu ile açmanız önerilir.)
